Docker Web Server Project

Task 4 - Deploying a Web Server Using Docker Containers

Name: Vivek

Project Overview

This project demonstrates the deployment of a web server using Docker containerization technology. The objective was to learn Docker basics, deploy an Nginx web server, monitor container health, manage container lifecycle operations, and understand real-world application deployment practices using containers.

Project Objectives

  • Learn Docker containerization fundamentals.
  • Deploy and manage a web server using Docker.
  • Understand Docker container lifecycle management.
  • Monitor container health and resource consumption.
  • Troubleshoot Docker-related issues.
  • Implement best practices for containerized deployments.

Environment Setup

Component Description
Operating System Ubuntu on WSL2
Container Platform Docker Engine
Web Server Nginx
Browser Testing localhost:8081
Additional Service Jenkins running on port 8080

Implementation Steps

  1. Installed and verified Docker using the Hello-World container.
  2. Pulled the official Nginx image from Docker Hub.
  3. Created and managed Docker containers.
  4. Mapped container port 80 to host port 8081 because port 8080 was already occupied by Jenkins.
  5. Started and monitored the Nginx web server.
  6. Accessed the server through a web browser.
  7. Explored container shell access using Docker Exec.
  8. Analysed logs, statistics, and configuration details.

Docker Commands Used

  • docker run hello-world
  • docker pull nginx
  • docker images
  • docker ps
  • docker run -d --name webserver -p 8081:80 nginx
  • docker logs webserver
  • docker stats webserver
  • docker inspect webserver
  • docker exec -it webserver bash
  • docker stop webserver
  • docker start webserver
  • docker rm webserver

Challenges Faced

  • Docker socket permission denied issue.
  • Docker group membership configuration.
  • Port conflict with Jenkins on port 8080.
  • Container name conflict during recreation.
  • Learning Docker command syntax and lifecycle management.

Solutions Applied

  • Added the current user to Docker group.
  • Restarted WSL session to refresh permissions.
  • Used port 8081 instead of 8080 due to Jenkins occupancy.
  • Removed conflicting containers and recreated them correctly.
  • Verified deployment using browser testing and Docker monitoring commands.

Monitoring and Troubleshooting

The Docker container was monitored using container logs, statistics, inspection reports, and interactive shell access. Resource utilization, network configuration, process information, and server response were validated successfully.

  • Container Logs - docker logs webserver
  • Resource Monitoring - docker stats webserver
  • Container Inspection - docker inspect webserver
  • Container Access - docker exec -it webserver bash

Project Outcome

The Nginx web server was successfully deployed within a Docker container. Port mapping was configured successfully on port 8081. The container remained operational and accessible via a web browser, demonstrating the practical implementation of Docker containerization technology.

The project enhanced understanding of image management, container deployment, lifecycle management, networking, volume concepts, monitoring, and troubleshooting in Docker environments.

Conclusion

This project successfully demonstrated the use of Docker for deploying and managing a web server. By using containerization, applications can be deployed consistently across environments while maintaining portability, scalability, and ease of management. Docker simplifies application deployment and is a fundamental technology in modern DevOps and cloud-native development workflows.
